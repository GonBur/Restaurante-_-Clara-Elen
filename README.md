# ClaraElen — Sitio Web de Restaurante

Sitio web completo para el restaurante **ClaraElen**, con el logotipo proporcionado integrado en el encabezado, sección de identidad, tarjeta flotante, favicon y pie de página.

│   │   ├── menu.js
